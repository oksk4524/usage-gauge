## 실행

실제 로컬 기록은 빌드 후 `.build/LocalUsage.exe --live`로 읽습니다. 기본 한도는 전체 1GiB, 파일당 128MiB, 한 줄 2MiB, 파일 10,000개, 45초입니다. 한도에 도달하면 부분 집계라고 표시합니다. 큰 기록을 전부 읽는 별도 검증에서는 `Options`를 명시적으로 8GiB / 512MiB / 180초로 높였습니다. 시간 제한은 협력적 제한이며, 진행 중인 파일시스템 호출을 강제 중단하지는 않습니다.

호출 프로그램은 첫 파일 작업 이전에 `Collector.InitializePathHandling()`을 호출해야 합니다. 이 Windows/.NET Framework 검증 코드의 긴 경로 호환 초기화입니다. 기존 UI 프로세스에 늦게 로드하는 통합 방식은 검증하지 않았습니다.

## 범위와 계산

- Claude: `projects` 아래 JSONL에서 입력·출력·캐시 읽기·캐시 생성만 합산합니다. 요청/메시지 ID로 중복 블록을 제외하고 스트리밍 출력의 증가를 처리합니다.

- Antigravity CLI: 각 `brain` 대화의 `.system_generated/logs/transcript_full.jsonl`만 읽습니다. 중복 파생 로그는 읽지 않습니다. 완료된 응답의 입력+출력을 합산하고 캐시 읽기는 별도로 표시합니다. 공식 헤드리스 출력과 같은 필드명이라는 근거로 해석한 것으로, 실제 청구 내역과의 대조 검증은 아닙니다.

## 보안 및 제한

인증 파일을 읽거나 갱신하지 않고, 네트워크·외부 CLI도 실행하지 않습니다. 원본 로그는 토큰을 찾기 위해 로컬에서 읽지만, 대화·도구 내용을 JSON 객체로 보관하지 않도록 화이트리스트 투영을 사용합니다. 결과에는 날짜·합계·수집 진단만 직렬화합니다. 캐시에 원문 대화는 저장하지 않습니다.

재분석 지점은 탐색에서 제외하며, 실제 열린 파일 핸들의 최종 경로가 선택한 루트 내부인지 확인한 후 내용을 읽습니다. 캐시는 파일 크기·수정 시각·운영체제 변경 시각으로 무효화합니다. 운영체제 변경 시각을 얻지 못하면 캐시를 재사용하지 않습니다. 캐시는 메모리 전용이며 프로세스를 닫으면 없어집니다. Collector는 단일 스레드 호출용입니다.

합성 시험 40개가 통과했습니다. 중복, 스트리밍 증가, 잘린 행, 오버플로, 시간대, 읽기 제한, 긴 경로, 같은 크기와 복원된 수정 시각의 변경 감지, 열린 핸들의 루트 경계, 원문 미출력을 포함합니다. 동시 링크 교체 경쟁 자체를 실시간으로 재현한 시험은 하지 않았습니다.
