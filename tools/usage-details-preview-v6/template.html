서버에서 확인

계정 사용량

Codex는 누적·일별 토큰과 계정 한도, Claude는 계정 한도, Grok는 한도·크레딧을 확인했어요. 제공하는 항목과 갱신 주기는 서비스마다 달라요.

별도 범위로 연결

이 PC의 세부 토큰

Claude·Grok·Antigravity는 이 PC에 남아 있는 최근 30일 토큰 기록을 연결했어요. 다른 PC·웹·삭제한 기록은 빠질 수 있고, 계정 전체 통계와 합산하지 않아요.

왜 최신 그래프가 오늘까지가 아닌가요?

Claude 인증 문제는 해결됐나요?

Antigravity는 왜 자동 조회에서 빠졌나요?

토큰은 로컬 기록에서 가볍게 읽고, 크레딧은 한 번 조회한 숫자를 표시해요. 이번 잔액 조회는 약 6.8초와 관측 메모리 157MiB를 사용했어요. 시안은 CLI를 실행하지 않으며, 향후 실제 앱에도 상시 조회를 연결하지 않았어요.

이 화면이 계정 정보를 외부로 보내나요?

아니요. 이 파일에는 날짜와 사용량 등 표시용 기록만 들어 있고, 로그인 토큰·이메일·대화 내용은 없어요. 외부 스크립트·폰트·API를 호출하지 않고 자동 갱신도 하지 않아요. 다만 개인 사용량이 담긴 파일이니 공유할 때는 주의해 주세요.
