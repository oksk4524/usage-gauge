## 막대 선택 배경과 즉시 툴팁
- 추가 막대처럼 보이던 전체 높이 선택 배경을 제거하고 실제 데이터 막대만 강조.
- 마우스 호버/이동, 클릭, 키보드 초점에서 날짜와 정확한 값 표시. 누락은 기록 없음으로 표시. 이탈/스크롤/바깥 누름/Escape에서 닫힘.
- PC 1440px와 모바일 폭 320/390px에서 값/경계/닫힘 확인. 터치 경로는 이벤트 회귀시험이며 실물 폰 검증은 아님. 회귀시험과 수치 보존 225건 통과.

## 항상 보이는 막대 값
- 각 기록된 막대 위에 짧은 근삿값을 표시. 좁으면 숫자와 단위를 두 줄로 나눔. 정확한 값은 기존 툴팁/키보드 안내 유지. 누락값에는 숫자 라벨을 붙이지 않으며 실제 0은 0으로 표시.
- 320/390px 한영 7일/30일/전체 12조건에서 값 라벨끼리 겹침과 차트 밖 잘림 없음. 수치 보존 225건 및 회귀시험 통과. 실물 폰 검증 아님.

## 그래프 디자인 재정리
- 숫자/단위의 반복 줄바꿈을 없애고 공통 단위를 제목 오른쪽에 한 번 표시. 선택값 상시 줄은 보조기기용으로 유지하고 정확한 값은 기존 툴팁에서 제공.
- 모든 막대와 짧은 날짜를 중앙 정렬. 왼쪽 수치축 중복을 없애 넓이를 회수하고 한 줄 숫자와 막대 간격을 정리. 아주 작은 양수는 <0.01로 구분하며 0으로 반올림하지 않음.
