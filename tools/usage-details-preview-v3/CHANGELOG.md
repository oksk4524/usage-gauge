# UsageGauge 디자인 수정 시안 v3

## 목적과 방향
- 목적: 선택한 출처의 사용량과 계정 한도를 혼동 없이 확인한다.
- 1순위: 기록된 합계와 주의가 필요한 저장 한도값.
- 방향: 장식보다 숫자, 정보 위계와 조작 안정성이 우선인 정보형 대시보드.

## 반영한 디자인 수정
- 모든 화면: 언어와 테마를 정상 흐름의 헤더로 이동. 모바일 중복 메뉴와 제목을 현재 화면 선택으로 통합. 서비스 선택과 기간 선택은 별도 역할을 유지한다.
- 사용량: 좁은 화면에서도 평균값을 유지한다. 토큰 구성값은 정렬된 묶음으로, 계정 한도 패널은 내용 높이로 표시한다. 낮게 기록된 한도는 모바일 상단에서 각 구간별로 안내하고 상세로 이동할 수 있다.
- 그래프: 320px 화면에서 7일 그래프가 실제 가용 폭을 사용한다. 리사이즈 시 선택된 막대의 초점, 상세값과 가로 스크롤 위치를 유지한다. 축과 날짜 글자는 12px 이상이다.
- 일별 기록: 날짜 다음에 합계를 유지하고 숫자와 고정 열 경계를 정리했다. 캐시 생성, 추론, 합산 기준은 삭제하지 않았다.
- 분석: 요약과 분류, 시간대 정보의 간격 및 PC 그리드를 정리했다. 미지원 정보는 접어서 유지한다.
- 수집 상태: 메타데이터를 라벨과 값의 2열로 정렬하고 지나친 열 간격을 줄였다. 모바일 수집 시각은 경과 시간으로 간결하게 표시하며 정확한 시각은 상세에 남긴다.
- AI 안내: 입력과 명령 영역의 간격, 읽기 크기를 정리했다. 공유 고지와 읽기 전용 범위를 유지한다.
- 공통 상세: 펼침 화살표, 짧은 화면의 팝업 내부 스크롤과 닫기 버튼, 화면 이동 후 초점과 맨 위 복귀를 보완했다.

- 기존 v1, v2 HTML 및 데이터 원본을 보존했다. 새 코드만 tools/usage-details-preview-v3에 있다.
- 9개 출처, 9개 한도 구간의 수치 보존 검사 225건 통과. 기존 회귀시험과 v3 추가 시험 통과.
- 한영 5개 화면 x 7개 너비 = 70조건, 어두운 테마와 짧은 높이 15조건을 추가해 총 85조건에서 문서 가로 넘침과 헤더 겹침 없음.
- 너비: 320, 360, 390, 430, 768, 1440, 1920px. 짧은 높이는 480px.
- 추가 실제 조작: 화면 크기 변경 후 차트 초점/상세값 유지, 마지막 기록 기준 30일, 모바일 하단 링크의 초점/상단 복귀, 한도 상세 이동, 팝업 닫기와 마지막 항목 접근.
