# 사용량 상세 수집 기초 검증 (2026-10-29)

검증용 시제품이며 본 위젯에는 연결하지 않았습니다. UI 변경·설치·기존 앱 재시작·인증파일 갱신·커밋·푸시는 하지 않습니다. 외부 패키지 없이 Windows .NET Framework C# 컴파일러로 빌드합니다.

## 실행

- .\Validate.ps1 기본 실행: 로컬 가짜 HTTP 서버/합성 JSON 시험 30개 + 가짜 로그인 파일·한글 공백 경로 시험 15개. 실제 계정 조회 없음.
- .\Validate.ps1 -Live: 위 시험 후 저장된 CLI 로그인으로 공식 서버에 읽기 전용 GET 각 1회. 인증 갱신·재시도 없음. 개인 사용량 합계가 콘솔에 나오므로 공개 로그로 올리지 말 것.
- .\Validate.ps1 -Credits: 위 시험 후 agy 1.1.11 이상에서 공식 /credits 무추론 조회 1회. CLI 자체의 내부 인증 갱신·로그 기록까지 통제하지 못함. 출력은 값 없이 구조만 반환.

PowerShell에서 예: .\Validate.ps1 대신 ..\Validate.ps1 사용. 임시 빌드·가짜 파일은 실행 종료 때 삭제합니다.

## 실제 계정 확인 결과

- Codex: 직접 GET 2회 HTTP 200. 일별 항목 235개의 합계와 서버 누적값 일치. 마지막 날짜 2026-10-27로, 검증일보다 늦게 갱신됨. 웹의 일반 ChatGPT 대화까지 포함된다고 검증한 것은 아님. 서버 집계 정의와 날짜 경계를 보존해야 함.
- Claude: 직접 GET 2회 HTTP 200. 5시간·주간 사용률 확인. 이 응답에 개인 계정 전체 토큰 이력은 확인되지 않음.
- Grok: 직접 GET 2회 HTTP 200. 사용률과 크레딧 잔액 확인. 현재 응답에는 history 없음. 누락을 0건으로 바꾸지 않음.
- Antigravity 1.4.9: /credits 실제 성공 응답은 remaining_credits, upgrade_uri뿐. 이 계정에서 소비 이력은 확인되지 않음. 첫 실행의 측정 도구가 종료 후 프로세스 메모리를 읽다가 실패하여 수정 후 재시험함.

## 측정

- 직접 조회 실행파일 15,872바이트. 첫 순차 조회의 프로세스 최고 작업집합 약 36.9MiB, 재시험 약 36.6MiB. 기존 위젯에 더해지는 메모리 크기를 측정한 것이 아님.
- 첫 조회 전체 시간: Codex 12,973ms / Claude 550ms / Grok 307ms.
- 재시험 전체 시간: Codex 1,075ms / Claude 430ms / Grok 261ms. 네트워크 구간 각각 758/425/257ms. 표본 2회로 평균 성능이나 모든 PC의 성능을 보장하지 않음.
- Antigravity 성공 시험: 18,035ms, 100ms 간격으로 관측한 CLI 최고 작업집합 169,426,944바이트(약 161.6MiB), 관측 CPU 1,468.75ms. 전체 자식 트리의 합산 메모리가 아님. 상시 조회에 부적합하여 보류 권장.
- 작은 합성 응답 10,000회 파싱: 저장한 실행 절차 재시험 188ms/CPU 140.625ms. 실제 대형 이력의 벤치마크가 아님.

## 검증된 방어

- 고정 HTTPS 주소 3개만 실제 조회, 리다이렉트 거부, GET만 사용.
- 로그인 파일 읽기 공유 허용, 64KiB 상한. 새 파일·refresh POST·자격정보 기록 없음.
- 압축 해제 후 응답 512KiB 제한, JSON 깊이 24, 이력 최대 4,000개.
- 64비트 정수 보존, 잘못된 숫자·중복 날짜·합산 오버플로 거부. 누락과 0 분리.
- 인증 오류/요청 제한에 즉시 재시도 없음. 원문 응답·토큰·stderr 저장 없음. 결과는 허용한 통계만 출력.
- CLI는 고정 /credits 인자, stdout/stderr 한도, job object 종료 처리. job 할당 실패 시 중단. 시작 직후 할당 전 자식 생성의 경합까지 제거한 구현은 아님.
- 확인한 Codex/Claude/Grok 인증파일 및 조사한 Antigravity 루트 인증 관련 파일의 크기·수정시각은 전후 동일. 전체 디스크 무변경이나 바이트 단위 동일성을 보증하는 검사는 아님.
