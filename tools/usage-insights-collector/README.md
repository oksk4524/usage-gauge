# UsageGauge 별도 사용량 수집기

기존 위젯과 분리된 수동 검증 도구입니다. 일반 CLI와 MCP 조회는 이 수집기를 실행하지 않습니다. 설치, 자동 수집, 알림, 인증 갱신, 기존 앱 설정 변경을 하지 않습니다.

## 출처

- Claude: `.claude/projects`의 응답별 토큰 필드. 응답과 요청 식별자로 중복을 제거하고 스트리밍 갱신의 최대 출력값을 사용합니다.
- Grok: `.grok/sessions`의 `usage.json`. 입력에는 캐시 읽기, 출력에는 추론이 포함되므로 이를 다시 더하지 않습니다.
- Antigravity: `brain`의 정식 `transcript_full.jsonl`. 입력과 출력을 더하고 캐시 읽기는 별도 표시합니다. 이는 요금 산정 규칙을 검증한 결과가 아닙니다. 토큰 수치가 없는 응답은 제외하고 개수를 표시합니다.
- Aside: 읽기 전용 `state.db`와 `messages.jsonl`의 사용량 메타데이터. 실제 응답의 provider와 model로 분류합니다. `claude-code`, `openai-codex`, `xai-grok-oauth`를 구분합니다.
- Aside 복구 요약: 메시지 파일이 없는 세션의 DB 턴 카운터. 당시 모델은 추정하지 않습니다. 종료 시각, 마지막 메시지 시각, 시작 시각 순으로 날짜를 정하며 시간대 분석에는 넣지 않습니다.
- Codex 계정 통계와 한도: 별도 조회가 이미 저장한 수치 결과만 `assemble.cjs`가 읽습니다. 이 스크립트에는 계정 조회 코드가 없습니다.

출처 간 중복 여부가 확인되지 않았으므로 합산하지 않습니다. `Aside` 공급자가 별도로 남는 경우 다른 서비스로 임의 귀속하지 않습니다. 프로젝트와 세션 식별자는 해시로 가립니다. 기존의 16자리 해시 식별자는 화면과 CLI에서 동일하게 유지합니다.

## 실행

Node.js의 내장 SQLite가 필요합니다. 별도 패키지 설치는 없습니다.

```powershell
node .\collect.cjs --live --output "저장경로\local.json"            # 기본: 증분 저장소
node .\collect.cjs --live --output "저장경로\local.json" --full     # 상태를 남기지 않고 전부 읽기
node .\tests.cjs
node .\regression-tests.cjs
```

기본 방식은 증분 저장소(`indexed.cjs`)입니다. 위치는 `%LOCALAPPDATA%\UsageGauge\usage-index.sqlite`이고 `--index 경로`로 바꿀 수 있습니다. 처음 한 번은 기록을 전부 읽고(이 PC 실측 약 2.5분), 그다음부터는 바뀐 파일의 새 줄만 읽고 바뀐 요청만 다시 합산합니다(실측 약 1.7초, 최대 메모리 약 100MB). 저장소에는 요청별 숫자, 해시로 가린 식별자, 이 PC 화면용 폴더 이름이 들어가며 대화 내용은 들어가지 않습니다. 예전 방식은 `--cache-dir`(파일별 결과)와 `--store`(결과 파일 하나)로 남아 있습니다.

중복 규칙: 같은 요청이 여러 파일에 있으면 처음 시작된 대화 파일의 사본을 씁니다(Claude는 출력이 가장 큰 기록, Aside는 합계가 가장 큰 기록). 예전 방식은 가장 최근에 바뀐 파일을 써서 오래된 대화를 열 때마다 세션 배정이 바뀌었습니다. `--extra-aside-root 경로`를 주면 보관 폴더로 옮겨진 Aside 세션도 읽기 전용으로 포함합니다.

`assemble.cjs`에는 `--local`, `--codex`, `--limits`, `--antigravity-limits`, `--output`으로 저장 파일을 지정합니다. `--local`과 `--output`만 필수이며, 계정 결과 파일은 빠져 있거나 실패해도 정상 출처를 계속 저장합니다. 실패한 계정·한도는 `unavailable`과 null로 표시합니다. 계정 조회 결과를 새로 가져오지는 않습니다. `verify-snapshot.cjs`에는 최종 스냅샷 경로와 검증 영수증 경로를 지정합니다.

## 안전성과 한계

- 원본 대화 파일은 토큰 메타데이터 추출에 필요한 범위에서 읽지만, 대화 내용, 제목, 이메일, 인증 정보, 원본 경로는 결과나 숫자 캐시에 저장하지 않습니다.
- JSON 오류의 원문 조각도 진단 결과에 남기지 않습니다. 비공개 세션은 집계에서 제외합니다.
- 사용량 기록이 하나도 없는 출처의 토큰 합계는 null입니다. 실제 0토큰 응답이 관측된 경우에만 0을 유지합니다. `node regression-tests.cjs`로 이 구분과 부분 출처 장애를 검사합니다.
- 실제 경로를 읽기 전후에 확인하고 심볼릭 링크를 따라 탐색하지 않습니다. 이 Node 실험 수집기는 기존 C# 수집기의 열린 핸들 기반 경계 검사와 동일한 구현은 아닙니다.
- 활성 파일의 크기나 시각이 바뀌면 부분 집계로 표시합니다. 최초 스캔은 최대 약 240초, 16GiB, 행당 8MiB로 제한합니다. 제한 초과는 누락 진단으로 남습니다.
- 숫자 캐시는 파일 서명과 관측 시작일을 확인합니다. 날짜가 바뀌어도 범위를 만족하면 재사용합니다. 활성화된 큰 로그는 다시 읽으므로 캐시 조회도 항상 빠르지는 않습니다.
- 노출되지 않는 구성요소는 null입니다. Claude의 별도 추론 수, Antigravity의 별도 추론 및 캐시 생성, Grok의 캐시 생성 값을 0이라고 표시하지 않습니다.
- 마지막 수집일과 불완전한 출처는 부분 집계로 표시합니다. 기록이 없는 날짜를 0으로 채우지 않습니다.
- 직접 사용 여부는 추정하지 않습니다. 부모 세션 또는 정기 실행 식별자가 있는 경우만 자동화로 표시하고 나머지는 미확인입니다.
- 토큰 이벤트 시각은 근무 시간, 실제 활동 시간, 수면 시간, 생산성이 아닙니다. 비용, 예측, 알림은 제공하지 않습니다.
- 계정 일별 날짜는 서버가 제공한 날짜 그대로이며 서버의 일자 구분 시간대는 미확인입니다. 계정 저장 결과의 파일 저장 시각을 수집 시각으로 표시합니다.

## 2026-10-29 검증 범위

최근 30일의 로컬 기록과 2월 10일부터 제공된 Codex 계정 일별 기록을 연결했습니다. 메시지 파일이 없는 Aside 세션 중 249개에서 391개 턴 요약을 별도 복구했습니다. Antigravity의 수치 없는 응답 684개는 여전히 집계에서 제외됩니다.

수집기 회귀시험은 17개입니다. 별도 CLI/MCP와 시안 시험, 실제 스냅샷의 기간별 합계, 프로젝트와 세션 및 모델 분류 합계, 시간대 합계 대조는 각각 해당 도구에서 실행합니다. 데이터는 실행 시점 이후 자동 갱신되지 않습니다.
